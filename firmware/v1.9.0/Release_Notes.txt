# FPVGate v1.9.0

FPVGate 1.9.0 times up to eight pilots from a single ESP32-C5 receiver. It adds support for the C5MK AIO and lets race directors set up an event, run heats, and review results from the gate.

## Multi-pilot racing

- Set names, colours, channels, and Enter/Exit thresholds per pilot. Live calibration shows each pilot's RSSI and the receiver status. Raceband R8 is supported.
- Follow live standings and lap times. Add a manual lap for any pilot from the race screen.
- C5 heats can stop at a lap target or time limit, then save the results even if every browser is closed.
- The C5MK AIO uses a 95 ms median filter and receiver sample timestamps. Its crossing detector rejects short spikes and treats brief signal dips during a pass as part of the same crossing.

## Event Director

- Enter pilots in bulk, generate groups, assign channels, and preview the heat schedule. Seed by Elo or best lap, and import or export an event.
- Choose Guided, Club, or Custom under Settings > User Interface. Use a schedule dashboard, a single-heat view, or the full-page editor. Each browser remembers its display settings.
- Run Event, Pilots & Setup, and Results have their own views. The gate can prepare the next heat for you to start, and optional result review pauses progression until you confirm.
- Corrections retain the original pilot identities. Skipped heats remain marked, and the gate can reconcile a saved result after a restart.

## Race history and Visual Marshal

- Record all eight RSSI traces to SD. In Visual Marshal, inspect individual passes and edit, remove, or merge laps.
- Review fastest lap, fastest three consecutive laps, best three laps, and median. The race views include Results, Laps, Race Flow, and Consistency.
- Browse history by day and session. Search, sort by title, filter by pilot, date, lap total, or import status, and export a complete backup.
- Imports preserve timestamps. Bulk import and clear handle larger multi-pilot histories more reliably.

## Announcements, radio control, and settings

- Choose Beep Every Lap, Say Lap Time Too, or consecutive-lap announcements. Preview crossing sounds and download voice packs.
- Start and stop races from a radio switch with the opt-in ELRS Backpack beta. Set up the TX backpack binding phrase and DVR Rec switch, choose the start position, and check the last command in Settings. Radio starts use the configured countdown.
- C5 crossings flash the gate LEDs. Configuration uses a desktop sidebar and a compact menu on phones. The interface supports English, German, Spanish, French, and Simplified Chinese.

## Receivers, RotorHazard, and networking

- Standard C5MK AIO wiring uses the c5mkaio receiver image on D6/D7 (C5 TX GPIO11 and RX GPIO12). Legacy D4/D5 wiring uses xiaoc5. Pair the AIO with [C5MK v1.3.0](https://github.com/LouisHitchcock/FPVGateC5MK/releases/tag/v1.3.0).
- Update an online C5 receiver with a matching image under Settings > System. The gate checks the receiver's trial boot before reporting success.
- RotorHazard plugin protocol 2 sends passes from every pilot, full-resolution RSSI at 20 Hz, and pass peaks for Marshal. Use the test-pass endpoint to check a split-gate setup. [RotorHazard plugin downloads](https://github.com/LouisHitchcock/fpvgate-rh-plugin/releases)
- Waveshare ESP32-S3-ETH supports DHCP and a direct Ethernet connection at 192.168.8.1. The Wi-Fi access point uses 20 MHz channels.
- Diagnostics include C5 receiver checks, a buzzer test, memory and connection statistics, a downloadable 16 KB log that survives software resets, optional SD logging, and core dumps.

## Install

Choose your board in the [FPVGate web flasher](https://fpvgate.xyz/flasher.html).

- FPVGate C5MK AIO
- FPVGate Novacore AIO
- Seeed XIAO ESP32S3
- Waveshare ESP32-S3-ETH
- ESP32-S3 DevKitC-1

Solo and XIAO ESP32S3 Plus retain their existing 1.8.x releases.

Back up settings, Event data, and race history. For compatible 1.8.x and 1.9.0 alpha builds, update both the app and filesystem. From 1.7.x, use a full USB flash for the updated partition table. The USB package includes boot_app0.bin so a gate previously updated over the air starts the newly flashed app. Use the separate C5 package to update the receiver.
